User Story 1 — Criar perfil

Como usuário, quero criar meu perfil com nome, e-mail e foto para ser identificado na rede.

Critérios de aceitação:


-Nome e e-mail são obrigatórios.

-Foto de perfil é opcional.

-Os dados ficam salvos e associados a esse usuário em todos os grupos dele.

---------------------------------------------------------------------------------------------------
User Story 2 — Criar grupo

Como usuário, quero criar um grupo público ou privado para reunir pessoas com um interesse em comum.

Critérios de aceitação:


-Nome do grupo é obrigatório; descrição é opcional.

-Grupo público: qualquer um entra direto. Grupo privado: precisa de convite.

-Quem cria o grupo vira administrador automaticamente.

---------------------------------------------------------------------------------------------------
User Story 3 — Publicar e curtir atualizações

Como membro de um grupo, quero publicar uma atualização curta e curtir as dos outros para compartilhar e interagir com novidades do grupo.

Critérios de aceitação:


-O texto do post tem no máximo 280 caracteres.

-Data e hora são registradas automaticamente.

-Cada usuário só pode curtir o mesmo post uma vez.

-O post só aparece para quem é membro daquele grupo.

---------------------------------------------------------------------------------------------------
User Story 4 — Comentar em um post

Como membro de um grupo, quero comentar em um post para participar da conversa sobre aquela atualização.

Critérios de aceitação:


-Cada comentário tem autor, texto e data/hora.

-O texto do comentário tem um tamanho máximo definido.

-Os comentários aparecem em ordem cronológica junto ao post.

---------------------------------------------------------------------------------------------------
User Story 5 — Feed consolidado

Como usuário, quero visualizar um feed com as atualizações de todos os grupos que participo para acompanhar tudo em um só lugar.

Critérios de aceitação:


-Reúne posts de todos os grupos do usuário.

-Ordenado do mais recente para o mais antigo.

-Indica de qual grupo é cada post.

---------------------------------------------------------------------------------------------------
User Story 6 — Gerenciar membros do grupo

Como administrador de um grupo, quero promover ou remover membros para manter a comunidade organizada.

Critérios de aceitação:


-Só um administrador tem permissão para promover ou remover membros.

-Um membro removido perde acesso aos posts do grupo.

-A ação fica registrada com data e responsável.
